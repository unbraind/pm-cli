## Shared experiment contract

Each proposal names its source, bounded SDK contract, inputs, evaluation population,
costs, deterministic fallback, and promotion or rejection rule. Compare against
an unchanged baseline on held-out judgments. Report task success, critical-evidence
omission, ranking quality, tokens, latency, memory, and rebuild cost separately.

Use tiny, real-shaped, sparse/dense, returning-session, concurrent, and long-history
fixtures. A smoke run cannot certify million-item performance or fleet convergence.
Read and write through the public SDK; CLI and MCP remain adapters.

Historical descriptions may contain hypotheses about optimality, independence, or
constant-time behavior. Those are claims to test. State the assumptions required
by an approximation guarantee, and preserve missing evidence as unknown.

Promotion requires an explicit decision and passing current mandatory gates.
A proposed experiment does not authorize a production policy, adaptive learning,
or workspace-data export. Rejected experiments remain searchable evidence.

## Mathematical checks before promotion

- RRF's published offset of 60 was an empirical choice. Retain a deterministic
  baseline and test alternatives; it is not a universal calibration constant.
  [Cormack, Clarke, and Büttcher (2009)](https://cormack.uwaterloo.ca/cormacksigir09-rrf.pdf).
- A plain value-per-token greedy heuristic does not inherit every submodular
  approximation guarantee. Sviridenko's knapsack result assumes a nonnegative,
  nondecreasing submodular objective and uses partial enumeration with greedy
  completion. Representation exclusivity and negative penalties need their own
  analysis. [Sviridenko (2004)](https://www.sciencedirect.com/science/article/pii/S0167637703000622).
- WL subtree features scale with edges and refinement rounds in the published
  formulation. Our proposed use still needs bounded neighborhoods and an
  evaluation of whether structural similarity predicts useful project evidence.
  [Shervashidze et al. (2011)](https://www.jmlr.org/papers/v12/shervashidze11a.html).
